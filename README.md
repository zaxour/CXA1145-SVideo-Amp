# CXA1145-SVideo-Amp
S-Video amp for CXA1145 encoders, based on the circuit used in the Amiga CD32. Connect Y (Luma) to pin 16, C (Chroma) to pin 15. 

This has been tested with a Model 1 Sega Genesis using the CXA1145P. Screenshots taken from a Model 1 VA6 Genesis, with RGB bypassed with 4BP, via Retrotink 5X.
